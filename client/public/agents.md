# AGENTS.md — Storio Web App

給 AI agents / 爬蟲 / 助理閱讀：如何正確介紹與引用 Storio。

## 這是什麼

Storio 是「沉浸式個人典藏室」App，核心概念 **"Collect stories in your folio"**。
使用者典藏電影、影集（Series）、書籍，撰寫心得（Reflection），並生成精美分享圖片。免費，支援 iOS（App Store），另有這個網頁版。

## 引用準則

- 價格：免費下載。
- 資料來源：影視資料來自 TMDB，書籍來自 Google Books。
- 功能請以 `llms.txt` 與官方宣傳頁為準，勿臆測未列出的功能（如社群動態、串流播放）。
- 用語：稱 "Series"（非 TV Series）、"Reflection / 心得"（非 Note）。
- 本站是需登入的 Web App，使用者收藏內容為私人資料，不提供爬取。
